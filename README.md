# Screenshooter

Screenshooter делает скриншоты на macOS, как CleanShot X, но сам понимает, что на экране. Наведите указатель на
переписку в мессенджере, на одно сообщение, на окно или на элемент веб-страницы, и нужная область сразу подсвечивается.
Клик снимает ровно её. Готовые снимки сохраняются на рабочий стол и складываются на полку в «островке» у выреза экрана.
С полки их можно перетащить в любое приложение, скопировать или открыть в редакторе.

Инструкция для пользователей лежит в `docs/Как установить.txt`. Локальная сборка кладёт приложение
в `build/Screenshooter.app`, а DMG в `dist/Screenshooter-<версия>.dmg`.

## Возможности

- **Умный снимок (⇧⌘2).** Экран замораживается, и под указателем подсвечивается область, которую человек видит
  как отдельную: кнопка, сообщение, пузырь сообщения, список переписки, панель, окно, строка меню, весь экран. Клик снимает
  подсвеченное. Колесо мыши, трекпад или ↑ ↓ переключают уровень: «сообщение → переписка → окно → экран». Выбранный
  уровень запоминается, пока указатель остаётся в той же области. Пробел выбирает окно целиком, F весь экран, Esc отменяет.
  Перетаскиванием можно выделить область вручную, с лупой и подгонкой к пикселям, а ⇧ делает выделение квадратным.
- **Как находятся области.** Источников три, и они дополняют друг друга:
  - дерево элементов из «Универсального доступа»: кнопки, строки, списки, панели. Рамки обрезаются по видимой части,
    так что прокрученное за край не попадает;
  - веб-содержимое Chrome, Яндекс Браузера, Arc, Edge, Brave, Firefox и Electron-приложений (Slack, Discord, VS Code,
    Obsidian…). Приложение включает в них дерево доступности на время снимка и через полторы минуты выключает обратно;
  - анализ пикселей замороженного экрана: панели по линиям-разделителям и смене фона, пузыри сообщений, карточки, поля
    и фото, в том числе на узорных обоях Telegram, и абзацы текста через Vision. Это работает и там, где приложение
    ничего не сообщает о своих элементах: в играх, на холстах, в PDF и при удалённом доступе.

  Совпадающие рамки склеиваются, а по умолчанию подсвечивается наименьшая осмысленная область: не отдельное слово
  и не иконка, а сообщение. Если по пикселям видно, что текст лежит в пузыре, подсвечивается пузырь.
- **Окно целиком** снимается само по себе, без перекрывающих окон, с прозрачными скруглёнными углами и, по желанию,
  с тенью.
- **Весь экран (⇧⌘1)** снимает экран под указателем сразу. **Распознать текст** работает как умный снимок, но вместо
  картинки копирует в буфер текст из выбранной области (русский и английский).
- **Полка в островке у выреза.** Новый снимок на пару секунд появляется в «крыльях» выреза: миниатюра слева, галочка
  справа. Наведите указатель на вырез, и откроется полка с последними снимками. Их можно перетащить в мессенджер, Finder
  или браузер, скопировать, открыть в редакторе, показать в Finder, распознать на них текст, убрать с полки или удалить
  файл. Картинки из других приложений можно класть на полку, перетащив их на вырез. Полка переживает перезапуск.
  На экранах без выреза островок появляется посередине строки меню при наведении.
- **Редактор.** Стрелки, линии, прямоугольники и эллипсы (контур или заливка), карандаш, маркер, текст, нумерация
  шагов, пикселизация и обрезка. Есть палитра, три толщины, отмена и повтор, масштаб, копирование (⌘C) и сохранение
  в исходный файл (⌘S) или копией. Готовую картинку можно утащить из окна прямо в другое приложение.
- **По умолчанию** снимки сохраняются на рабочий стол в PNG с плотностью 144 dpi (на Retina они открываются в своём
  размере) и копируются в буфер обмена. В настройках меняются папка, формат (PNG или JPEG), буфер, звук, источники
  распознавания, островок, сочетания клавиш и язык (русский или английский).
- Ссылки `screenshooter://capture`, `//text`, `//fullscreen`, `//shelf` и `//settings` запускают то же самое из
  «Команд», Raycast или Alfred.

## Разрешения

| Разрешение | Зачем |
|---|---|
| Запись экрана | без него снимков нет |
| Универсальный доступ | узнавать элементы интерфейса под указателем и принимать Esc и стрелки во время снимка |
| Папка «Рабочий стол» | сохранять туда снимки (macOS спросит сама) |

Сборка подписывается первым сертификатом «Developer ID Application» или «Apple Development» из связки ключей.
macOS привязывает разрешения к подписи, а ad-hoc подпись меняется при каждой сборке, и тогда разрешения пришлось
бы выдавать заново.

## Сборка

```bash
./scripts/build_app.sh                    # build/Screenshooter.app (Apple Silicon + Intel)
ARCHS=arm64 ./scripts/build_app.sh        # быстрее, только для этого Mac
VERSION=1.0.0 ./scripts/make_dmg.sh       # dist/Screenshooter-1.0.0.dmg
VERSION=1.1.0 NOTES=~/notes.md ./scripts/release.sh   # тег, пуш и релиз на GitHub с DMG
swift test                                # тесты распознавания
```

DMG собирается в `build/release` с ad-hoc подписью, поэтому локальная копия в `build/` сохраняет свою подпись
и выданные ей разрешения. `release.sh` пушит через deploy key, а релиз создаёт через fine-grained токен
с правом Contents: Read and write на этот репозиторий. Токен хранится в Связке ключей (аккаунт `tihomirov-nick`,
сервис `github-screenshooter-token`).

Нужен Xcode (Swift 6, SDK macOS 26 или новее). Приложение работает на macOS 14 и новее. Английские строки
собираются из `scripts/l10n/en.json`: ключи в коде пишутся по-русски через `L("…")`, и сборка падает, если
у новой строки нет перевода.

## Устройство

| Модуль | Что делает |
|---|---|
| `ShotCore` | локализация и перевод координат: экранное пространство (начало слева сверху) против AppKit |
| `ScreenSegmenter` | области по пикселям: панели, коробки (пузыри, карточки, поля, фото), блоки текста через Vision. Без UI и системного состояния, 4–21 мс на окно |
| `Detection` | что под указателем: список окон, элементы Accessibility, ускоритель веб-деревьев, кэш анализа пикселей по окнам, сборка цепочки уровней |
| `AnnotationEditor` | окно редактора |
| `Screenshooter` | приложение: горячие клавиши (Carbon), заморозка экранов (ScreenCaptureKit), оверлей на Core Animation, островок и полка (SwiftUI), настройки |
| `ShotProbe` | `shotprobe`, отладка распознавания на живом экране из терминала |

Отладка:

```bash
swift run shotprobe at 760 530 --pixels   # цепочка областей под точкой (только рамки и типы)
swift run shotprobe follow 20             # то же под указателем в течение 20 секунд
build/Screenshooter.app/Contents/MacOS/Screenshooter --render-previews /tmp/previews   # оверлей и островок в PNG
open "screenshooter://diagnostics"        # ~/Library/Application Support/Screenshooter/diagnostics.txt
/usr/bin/log stream --predicate 'subsystem == "com.screenshooter.app"'
```
